### 1.3 既有代表基线卡点与本文训练/推理协议台账
- **既有四类路线卡点（支撑第 4 页 `1.2`）**：① 确定性二元回归（`Retinexformer`：均值化抹平细裂纹）；② 像素空间扩散（`Diff-Retinex / PyDiff`：计算开销大且纹理噪声同分布）；③ 二元内细节通路（`DiffLight / SMG`：非扩散无独立概率先验，极暗弱纹理难辨）；④ 二元潜在扩散（`Reti-Diff`：反射率先验混载基色与纹理，无专门纹理生成与注入）。
- **冻结 / 训练 / 推理边界（支撑第 5–8 页）**：初始分解器 $D(\cdot)$ 全程冻结；阶段一用成对 $(I_{LQ}, I_{GT})$ 联合训练 `Tri-RPE + Ti-former`（300k 步）；阶段二载入阶段一权重，训练 3 个参数独立的 `T-RLDM` 分支并联动图像级损失（400k 步）；测试推理无需 $I_{GT}$，单帧 $I_{\text{test}}$ 提条件 → 三分支从高斯噪声采样 $(\hat{Z}_R,\hat{Z}_L,\hat{Z}_T)$ → `Ti-former` 输出增强图。

### 1.4 多维实验对比与权衡/消融台账
- **公开集（表 2–5）**：4 个基准（`LOL-v1 / LOL-v2-real / LOL-v2-synthetic / SID`）覆盖四大路线 17 种方法，本文 FID 与 BIQE 全场最低（`LOL-v2-syn` FID 较 `Retinexformer` 降 `42.45%`），SSIM 全面优于/持平 `Reti-Diff`，PSNR 在真实拍摄 `LOL-v2-real` 反超而在其余三集存在 `0.42–1.96 dB` 像素—感知权衡。
- **工业自建集（表 8）**：`Hydro-Dark`（4000 对同机位 `<0.5px` 对齐、按巡检序列隔离 8:1:1）统一重训 300 epochs，四项指标全面超越 `Reti-Diff / AnlightenDiff / Zero-DCE / KinD`（PSNR `+2.30 dB`，SSIM `0.683→0.739`）。
- **消融闭环（表 6–7 + 3.5.5 节）**：分量消融（A `14.56 dB` / B `16.11 dB` / C `20.62 dB` → 完整 `23.75 dB`）+ 六步模块叠加四指标轨迹 + 梯度损失权重 $\lambda_2=\lambda_5=1.5$ 最优。
