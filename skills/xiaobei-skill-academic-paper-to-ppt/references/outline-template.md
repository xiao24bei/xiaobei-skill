# PPT 大纲标题：XXX

## 全局要求

- 默认生成约 12-18 页 PPT 大纲；如果原文很短或用户要求精简，可压缩到约 10 页。
- 所有事实内容必须来自上传的源文档；没有明确依据时写“原文未明确说明”。
- 如果用户提供 PPT/PPTX 模板，模板只用于视觉风格、页型结构和内容密度参考，不作为事实来源。
- 如果模板包含大量章节页或占位页，不要照搬模板页数；应压缩成适合源文档的汇报逻辑。
- 如果源文档是论文，优先保留背景、问题、相关工作、方法、实验、结果、分析、总结。
- 如果源文档是项目书或技术报告，且原文确实包含相关内容，可增加市场、应用场景、团队、实施条件等页面。
- 每页必须写清楚“原文直接说明 / 基于原文归纳 / 原文未明确说明”的边界。

每页使用以下字段：

### 页面类型
封面 / 目录 / 章节页 / 正文页 / 方法页 / 数据页 / 图表页 / 总结页 / 致谢页等。

### 页面标题
用于 PPT 页面上的主标题。

### 核心内容
写 3-5 条最重要的信息点。

### 内容展开
写 4-8 条可支撑页面生成的细节，包括关键定义、问题背景、方法步骤、实验设置、数据结果、结论依据、限制条件等。

### 建议展示方式
说明该页适合做成什么视觉结构，例如三栏卡片、流程图、技术路线图、对比表、结果图、结论卡片、时间线、章节分隔页等。

### 视觉生成要点
给 `$imagegen` 使用的页面视觉提示。若有 PPT 模板，写明对应模板页型和需要继承的视觉元素；若无模板，写明使用默认学术风格。

### 原文依据
列出该页内容来自原文的章节、段落、图表、公式、实验表格、页码或可定位线索。无法定位时写“原文位置未明确说明”。
