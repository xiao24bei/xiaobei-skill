## 1. 彻底根除“40字提词卡空壳”：导师五连问硬核标准

旧版学术 PPT 最致命的通病是**“视觉干净但内容极浅”**——每页只写 3–4 句十几个字的大白话口号、漏掉相关工作对标、角标标了公式号画面却没公式、17 个对比方法删剩 2 个点连线、甚至塞入 `PSNR` / `FID` 本科教科书定义式充数。

**每一套完整论文 PPT 必须正面回答并讲透以下「导师五连问」**：

### 第一问：应用场景有什么特殊退化？物理/数学问题本质在哪？（对应 `1.1` 页）
- **必讲要素**：
  1. **具体工程/科学工况约束**（如水电地下厂房封闭防爆限补光、金属强反光与极暗散粒/读出噪声并存，而非泛泛一句“低照度图像看不清”）；
  2. **核心科学矛盾**（如微裂纹/锈蚀颗粒与高频传感器噪声在频域与空间梯度响应上高度混叠，传统平滑去噪必然抹除关键缺陷边缘）；
  3. **完整形式化建模对比**：并列展示经典模型（如 $I = R \odot L$）与本文重构方程（如 $I = (R_{\text{base}} + \Psi(Z_T)) \odot L + N$），**逐一标清每个张量的空间维度（如 $\mathbb{R}^{H\times W\times 3}$）、物理含义及非线性映射 $\Psi(\cdot)$ 的具体实现结构（如两层 $1\times 1$ 卷积 + LeakyReLU 构成的 MLP）**。

### 第二问：前人主流路线做到哪一步、各自卡在哪？本文凭什么破局？（对应独立 `1.2` 页！）
- **严禁跳过相关工作直接画本文网络图！** 导师如果不看到你对 `Retinexformer`、`Diff-Retinex`、`DiffLight`、`Reti-Diff` 等核心基线的精准解剖，就无法判断你的工作是真创新还是硬凑模块。
- **必讲要素**：将原文第 1 节（或特性对比表 1）提炼为 **3–4 条代表性技术路线对比矩阵**：
  - 路线 1（确定性二元回归，如 `Retinexformer / URetinex-Net`）：优势是亮度色彩稳定，**卡点**是基色纹理混于反射率且回归条件均值解，极暗高频纹理易均值化抹平；
  - 路线 2（像素空间扩散，如 `Diff-Retinex / PyDiff`）：优势是生成能力强，**卡点**是高维像素空间显存/延时巨大，且纹理噪声仍共享同一分布；
  - 路线 3（二元框架内细节引导，如 `DiffLight / SMG`）：优势是增设细节分支，**卡点**是非扩散确定性通路缺乏独立概率先验，极暗强噪下仍难区分弱纹理与随机噪声；
  - 路线 4（二元潜在扩散直接基线，如 `Reti-Diff`）：优势是潜在空间高效生成，**卡点**是仅含光照/反射率二元先验，无法对高频纹理施加差异化概率建模与显式注入；
  - **本文破局闭环**：针对性提出「物理三元解耦 → 三独立潜在扩散先验生成 → 纹理交叉注意力显式注入」三位一体闭环。

### 第三问：每个模块怎么算？公式怎么写？谁冻结、谁训练、推理怎么跑？（对应方法 `2.1–2.4` 页）
- **四条方法深度铁律**：
  1. **真图 + 张量维度流**：无损嵌入原文总体框架图与各子模块结构图，卡片中明确写出特征变换链路与维度（如 `Conv3 → 5×ResBlock → AvgPool → Linear` 输出紧凑先验 $Z_R, Z_L, Z_T \in \mathbb{R}^{3C'}$；U-Net 四尺度编解码特征尺度 $H\times W\times C \to \frac{H}{8}\times \frac{W}{8}\times 8C$）。
  2. **引用公式 100% 真实上屏**：凡原文给出的核心公式——物理建模、跨注意力投影 $Q=W_Q F_R, K=W_K F_T, V=W_V F_L$、阶段一损失 $\mathcal{L}_{\text{Phase1}}$ 与梯度约束 $\mathcal{L}_{\text{Texture}}$、正向加噪 $q(Z^t|Z^{t-1})$、逆向去噪目标 $\mathcal{L}_{\text{Diff}}$、阶段二端到端图像级联合损失 $\mathcal{L}_{\text{Phase2}}$——**必须完整、准确地绘入对应方法页卡片！严禁角标写“式(6)-(8)”而画面零公式！**
  3. **冻结 / 训练 / 推理三态边界**：明确回答“初始分解器 $D(\cdot)$ 是否冻结？”“阶段一联合更新哪几个模块？”“阶段二训练扩散分支时为什么还要连回解码器施加图像级像素与梯度损失（防止潜在空间先验解码失真）？”“测试推理没有清晰参考图 $I_{GT}$ 时，数据流如何从单帧低质输入 + 纯高斯噪声采样闭环运行？”
  4. **设计动机（WHY）**：例如解释为什么在 Ti-former 里**必须用基色 $F_R$ 作 Query、纹理 $F_T$ 作 Key、光照 $F_L$ 作 Value**（用稳健低频基色骨架去检索高频缺陷空间位置，生成高频注意力权重去调制光照恢复，避免传统反射率自查询把暗部噪声一并放大）。

### 第四问：实验对比全不全？指标取舍怎么解释？消融每一步到底证明了什么？（对应实验 `3.1–3.7` 页）
- **四条实证深度铁律**：
  1. **严禁“砍掉 15 个基线只画两点连线”**：公开基准对比页必须呈现**四大路线代表性 SOTA 方法（≥ 5–7 个关键模型，如 `Zero-DCE / Retinexformer / Diff-Retinex / MambaIR / DiffLight / Reti-Diff / 本文`）在全部 4 项评价指标（如 `PSNR / SSIM / FID / BIQE`）上的完整对比格局**，并点明摘要核心量化亮点（如 `LOL-v2-synthetic` 上 FID 较 `Retinexformer` 降低 `42.45%`）。
  2. **直面指标分化与深度权衡归因**：若模型在感知/结构指标（FID/BIQE/SSIM）全面领先，而在部分公开数据集上逐像素 PSNR 略低于确定性/二元基线（如低于 `Reti-Diff` 0.42–1.96 dB），但在真实极暗强噪自建集上四项指标全部大幅领先（PSNR `+2.30 dB`），**必须把这一物理/统计机理讲透**：逐像素 MSE/PSNR 偏爱平滑条件均值解，生成式高频纹理细节在轻微相位偏移下会受像素级惩罚，而在极暗工业强噪场景中二元平滑导致严重结构失真，显式纹理扩散优势全面释放！
  3. **定性对比逐类解剖失败模式**：读图点评不能只写“基线模糊、本文清晰”10 个字，必须对照放大框逐一指出**轻量无参考方法的暗部噪声同步放大与色偏、非扩散细节方法在极暗区弱纹理误抹除、二元潜在扩散方法的全局干净但微裂纹/刻度笔画柔化**。
  4. **消融实验全指标分工归因（严禁单指标 + AI 套话！）**：分量消融（如去光照 A / 去基色 B / 去纹理 C）必须列出**完整四项指标退化数据**并解释各自违背的物理规律；逐步模块叠加消融必须结合 `PSNR + SSIM + FID + LPIPS` 多列变化，讲清**确定性纹理 vs 共享扩散 vs 三独立分支防串扰 vs 交叉注意力空间对齐（SSIM 大涨） vs 混合梯度损失锐化边缘（以及权重 $\lambda=1.5$ 网格搜索平衡点）**各自的不可替代分工！

### 第五问：离真实落地还有多远？下一步怎么验证？（对应 `4.1–4.2` 页）
- 坦诚且专业地交代三大边界与演进路径：① 多步逆向采样（$T=1000$）对端侧实时性的制约 → **扩散蒸馏 / 一致性模型加速**；② 探照灯直射金属铭牌等强镜面反光掩盖纹理 → **偏振成像 / 多曝光高动态融合**；③ 跨模态与下游任务闭环 → **可见光–红外热成像三元解耦扩展**，以及接入固定缺陷检测器定量评测漏检率与误报率。
