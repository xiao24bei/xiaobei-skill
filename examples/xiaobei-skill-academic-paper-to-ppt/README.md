# Academic Paper to PPT example

`defense_presentation.pptx` is a 14-slide, image-only presentation generated with `xiaobei-skill-academic-paper-to-ppt` from a published academic paper.

- Each slide contains exactly one full-slide bitmap image.
- The example has no speaker notes, comments, hidden objects, or private contact details.
- The paper authors, DOI, and research content remain attributed to their original rights holders; this file demonstrates the Skill's output format.
